# TrendFit | آگهی‌یار

رابط کاربری اولیه یک بازارگاه آگهی فارسی و راست‌چین با Next.js و TypeScript.

## اجرا

1. Node.js نسخه 20 یا بالاتر نصب باشد.
2. در ترمینال وارد پوشه `TrendFit` شوید.
3. اجرا کنید:

```bash
npm install
npm run dev
```

4. آدرس `http://localhost:3000` را باز کنید.

برای ساخت نسخه production: `npm run build` و سپس `npm run start`.

## صفحات نمونه

صفحه اصلی، دسته‌بندی، جست‌وجو، ثبت آگهی، جزئیات آگهی، پروفایل، آگهی‌های ویژه، ورود/ثبت‌نام، داشبورد کاربر، پنل مدیریت، قوانین و تماس با ما.

## وضعیت فعلی

این نسخه یک **نمونه اولیه سمت کاربر با داده‌های نمایشی** است. ورود، ذخیره‌سازی آگهی، پرداخت، ارسال پیام و مدیریت واقعی نیازمند بک‌اند، پایگاه داده، احراز هویت و درگاه پرداخت هستند و هنوز پیاده‌سازی نشده‌اند. دکمه‌ها و فرم‌های نمایشی نباید به‌عنوان سرویس واقعی استفاده شوند.
