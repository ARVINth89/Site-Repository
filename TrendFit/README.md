# TrendFit / آگهی‌یار

بازارگاه فارسی خدمات، فرصت‌های شغلی و معرفی کسب‌وکارها با تمرکز بر بازار ایران.

## وضعیت فعلی

رابط کاربری اولیه در حال حاضر شامل داده‌های نمایشی است. زیرساخت اولیه پایگاه داده در حال آماده‌سازی است؛ احراز هویت، عملیات واقعی آگهی، پنل مدیریت و پرداخت تا تکمیل و تست مسیرهای امن، قابلیت عملیاتی محسوب نمی‌شوند.

## فناوری‌ها

- Next.js App Router و React
- TypeScript
- PostgreSQL
- Prisma ORM
- Zod برای اعتبارسنجی ورودی‌ها

## راه‌اندازی محلی

1. Node.js 20 یا بالاتر و PostgreSQL نصب کنید.
2. در پوشه `TrendFit` دستور `npm install` را اجرا کنید.
3. فایل `.env.example` را به `.env` کپی و مقدار `DATABASE_URL` را تنظیم کنید.
4. دستورهای زیر را اجرا کنید:

```bash
npm run db:generate
npm run db:push
npm run dev
```

برنامه در `http://localhost:3000` اجرا می‌شود.

## بررسی کیفیت

```bash
npm run lint
npm run typecheck
npm run build
```

## مدل داده

مدل‌های اولیه شامل کاربر و نقش‌ها، آگهی و وضعیت انتشار، گزارش تخلف و سفارش هستند. مبالغ در کوچک‌ترین واحد ریال و از نوع عدد صحیح بزرگ ذخیره می‌شوند تا خطای اعشاری ایجاد نشود.

## امنیت و پرداخت

- دسترسی به منابع باید در سمت سرور و برای هر درخواست کنترل شود.
- نقش مدیر نباید از ورودی کاربر یا رابط کاربری قابل انتخاب باشد.
- پرداخت واقعی تا زمان اتصال درگاه مجاز، تأیید callback سمت سرور و تست idempotency فعال نیست.
- کلیدها و رمزها فقط باید در Secret/Environment تنظیم شوند؛ هرگز در Git ثبت نشوند.

## انتشار

برای انتشار، یک میزبان سازگار با Next.js، پایگاه داده PostgreSQL و متغیرهای محیطی امن لازم است. اجرای migration و تنظیم دامنه باید پس از فراهم شدن این دسترسی‌ها انجام شود.
